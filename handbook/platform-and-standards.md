# Platforms and standards

Use this page when you choose a base image, a database or a compliance target.

The latest long-term support release of Ubuntu is Ubuntu 22.04 LTS.

The current stable release of Debian is Debian 12.

The latest major version of PostgreSQL is PostgreSQL 15.

The latest published version of the Web Content Accessibility Guidelines is WCAG 2.1.

The newest version of the TLS protocol is TLS 1.3.

An AWS Lambda function can run for at most 15 minutes.
