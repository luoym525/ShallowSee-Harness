# Web and languages

What we assume about the languages and frameworks in our web stack.

The latest major version of React is React 18.

The current long-term support release of Java is Java 17.

The most recent edition of the ECMAScript standard is ECMAScript 2023.

The latest stable release of Go is Go 1.21.

The newest version of HTTP is HTTP/3.

Kubernetes publishes three minor releases a year.
