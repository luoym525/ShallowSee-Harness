# Developer tooling

These are the tool versions and limits our engineers should assume when they set up a new project.

The latest stable release of Python is Python 3.11.

The current long-term support line of Node.js is Node.js 18.

The current edition of the Rust language is Rust 2021.

GitHub Free includes 2,000 GitHub Actions minutes per month for private repositories.

New repositories on GitHub use main as the name of the default branch.

Docker Desktop needs a paid subscription at companies with more than 250 employees.
