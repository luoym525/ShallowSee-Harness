# Demo handbook

This folder is the knowledge base that Shelf Life audits in the demo. It reads like a small company's internal handbook, but every fact in it is a real, public, checkable one.

Some values are deliberately out of date. Which ones is recorded outside this folder, in `eval/drafts/handbook-author-intent.json`, so the audit never sees the answers. Please do not correct these pages by hand: the stale values are the test.

Each fact sits on its own plain line so that a correction changes exactly one value on one line.
