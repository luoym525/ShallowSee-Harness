# harness/console/web: the English web console

What a non-technical person uses: **Setup** (providers, CC Switch style), **Make a wish**, **Live run**, **Result**, **Runs**. Vanilla ES modules and CSS, no framework, no CDN, no build step, no npm dependencies. Served by the console server (`harness/console/server`, workstream 07) at `http://127.0.0.1:4320/`.

## Screens (hash routes)

| Route | Screen |
|---|---|
| `#/new` | Make a wish: big textarea, 4 example chips, budget summary, **Start**. Friendly card to Setup when no model is configured. |
| `#/runs/:id` | **Live run**: wish, status, elapsed, spend, iteration; the Plan → Build → Test → Reflect loop ring; work items with attempts and score bars; **Who's working** (role, model, the router's one-line reason, escalations); plan fact check; **Auto-approved by <model>** badge; README fact check ("Proposed, unreviewed"); sources; models table; timeline with expandable test evidence. When finished: **Open the product** (new tab on the preview origin `:4321`, never embedded). |
| `#/runs/:id/report`, `/files` | Rendered `REPORT.md` (tiny safe Markdown renderer) and a file browser (product files and run records). |
| `#/runs` | History with status, product, score, spend, date. |
| `#/setup` | Provider cards: name, Model/Search/GitHub badge, URL, key status (`sk-…ab12` or No key), model count, Enabled, **Test**, **Fetch models**, **Edit**, **Delete** (confirm). |
| `#/setup/new`, `#/setup/:id` | Add / Edit provider: preset chips, Provider name, Notes, Website, API Key, Request URL, Models, Advanced headers, sticky Cancel / + Add. |
| `#/routing` | Routing table (role · model · tier · reason, Auto / pin a model), autonomy (full autopilot vs confirm the plan), budget. |

Dark by default; the theme button cycles dark → light → system (system follows `prefers-color-scheme`). Animations respect `prefers-reduced-motion`.

## Files

| File | What |
|---|---|
| `index.html`, `styles.css`, `app.js` | Shell, tokens, hash router, theme toggle |
| `model.mjs` | **Pure** functions: events → view state (`reduceRun`, `applyEvent`, `approvalBadge`, `whoIsWorking`, `factCheckRows`, `fetchModelsOutcome`, formatters). No DOM. Tested. |
| `markdown.mjs` | Safe Markdown → HTML (escapes everything; only http(s)/mailto links) |
| `ui/*.mjs` | Screens (`run`, `wish`, `setup`, `provider-form`), DOM helpers (`dom`), the only network module (`api`) |
| `fixtures/` | `sample-run.jsonl` (events, `synthetic: true` in `room.created`) and `sample-run/` (artifacts and a made-up product). **Synthetic**: generated by `dev/make-fixture.mjs`. |
| `dev/mock-server.mjs` | Stand-in for the console server: static UI, every endpoint of `contracts/http-api.md`, in-memory providers (never holds a key), a replay of the fixture, and the preview origin |
| `dev/screenshots.mjs`, `dev/ui-smoke.mjs`, `dev/cdp.mjs` | Headless Edge/Chrome tooling (no dependencies) |
| `screenshots/` | Screenshots of every screen at 1280×720 (synthetic data) |

## Run it

```bash
node harness/console/web/dev/mock-server.mjs     # UI + mock API on :4320, preview origin on :4321
# open http://127.0.0.1:4320/#/new, type anything, press Start: a SYNTHETIC replay of about 45 s
MOCK_SPEED=20 node harness/console/web/dev/mock-server.mjs   # faster replay (default 10)
```

Every run started on the mock shows a **Synthetic replay** label. It always replays the same canned umbrella example, whatever you type. Against the real server (`node harness/console/server/index.mjs`) the same UI shows real runs and never shows that label.

Mock fetch-models scenarios, chosen by the Request URL: `deepseek` → key rejected (401), `127.0.0.1:11434` → can't reach, `example.com` → no model list endpoint, a URL containing `empty` → empty list, anything else → a list.

## Test

```bash
node --test "harness/console/web/**/*.test.mjs"       # offline, no browser, no keys
node harness/console/web/dev/ui-smoke.mjs             # click-through in headless Edge/Chrome (skips if none installed)
node harness/console/web/dev/screenshots.mjs          # regenerate screenshots/
node harness/console/web/dev/make-fixture.mjs         # regenerate the synthetic fixture
```

## Rules this UI keeps

- Never renders HTML from data: `textContent` everywhere; the one `innerHTML` is the output of `markdown.mjs`, which escapes first.
- Never shows or logs a key: the server sends only `{ hasKey, preview }`; a typed key lives in its input until sent, and the form never re-fills it.
- Approval wording: `Auto-approved by <model>` only for `approval.by === "model"`; `Confirmed by you` only after a `harness.plan.confirmed` event with `by: "user"`.
- Skipped or failed fact checks read "Not verified"; findings are "Proposed, unreviewed", never "Confirmed"; a passed `independent_sources` check is described as a mechanical check.
- Unknown is unknown: no cost shows "unknown", never `$0.00`.
- Unknown event types and fields are ignored; resent events (reconnect) are deduplicated by `seq`; SSE reconnects with `Last-Event-ID` / `?after=`.
