## Git handoff

The coordinator reviews explicit repository-relative paths and records their SHA256 values together with the exact base commit. The fixed publisher checks the manifest hash, source-file hashes, repository, branch, origin, index and remote base before staging only those files. It uses a normal push and verifies the resulting remote commit. A changed base or failed push is reported for integration rather than overwritten.

This workflow supports a contributor whose environment cannot push to GitHub. It does not share account credentials, remove another process's lock, change access controls or accept arbitrary commands from meeting messages.
